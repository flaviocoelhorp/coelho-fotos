# coelho-fotos

Fotos de QC dos produtos do CoelhoLifeStyle, servidas pelo CDN jsDelivr.

Cada arquivo em `qc/` segue o padrao `<idDoRegistro>_<n>.jpg`, onde `<idDoRegistro>`
e o id do ProdutoDestaque no Base44.

URL publica de cada foto:

    https://cdn.jsdelivr.net/gh/flaviocoelhorp/coelho-fotos@main/qc/<arquivo>
